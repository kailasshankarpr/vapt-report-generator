SQL Injection in Search Query Parameter

SLA: Immediate (within 24 hours)
Scanner: Burp Suite Professional

Database error 'syntax error near OR 1=1' was returned, and arbitrary database extraction was demonstrated. Parameter 'q' is concatenated directly into SQL queries without sanitization.

URL / Location: https://app.acme.com/search.php?q=test' OR 1=1--
Parameter: q
OWASP 2025: A05:2025 - Injection

Critical CVSS 9.1 New

AWS EC2 Instance Metadata SSRF Leak

SLA: Immediate (within 24 hours)
Scanner: Nuclei Vulnerability Scanner

Server-Side Request Forgery allows accessing AWS IMDSv1 internal endpoint at http://169.254.169.254/latest/meta-data/

URL / Location: https://api.acme.com/proxy?url=http://169.254.169.254/latest/meta-data/iam/security-credentials/
OWASP 2025: A01:2025 - Broken Access Control
MITRE ATT&CK: T1557 - Adversary-in-the-Middle, T1046 - Network Service Discovery

Proof of Concept / Evidence

Curl Command:
curl -X GET 'https://api.acme.com/proxy?url=http://169.254.169.254/latest/meta-data/iam/security-credentials/'

Extracted Findings:
AccessKeyId: ASIAIOSFODNN7EXAMPLE, SecretAccessKey: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY

Remediation Recommendation

Enforce IMDSv2 and restrict outbound HTTP requests to internal cloud metadata endpoints.

High CVSS 7.5 New

Broken Object Level Authorization (BOLA / IDOR)

SLA: High Priority (within 7 days)
Scanner: Burp Suite Professional

By modifying the user ID parameter from 1024 to 1025, the application returns sensitive PII records of another tenant user without authentication errors. The application fails to enforce object-level authorization checks when accessing user profiles via numeric ID parameters.

URL / Location: https://api.acme.com/api/v1/users/1024/profile
Parameter: id
OWASP 2025: A01:2025 - Broken Access Control
MITRE ATT&CK: T1059 - Command and Scripting Interpreter, T1068 - Exploitation for Privilege Escalation, T1190 - Exploit Public-Facing Application, T1110 - Brute Force, T1078 - Valid Accounts, T1083 - File and Directory Discovery

Remediation Recommendation

Enforce server-side authorization checks on all REST endpoints. Implement proper access control checks validating that the authenticated user owns the requested object ID.
